# Editable tutor-policy simulation lab

The one-output setup page correctly preserves immutable comparisons, but it hides
the editors after freezing. That interaction does not support the intended
researcher loop. Add a separate Marimo lab where current and proposed policy
drafts remain visible above the latest saved A/B outputs.

Every click creates `run-NNNN/` under one ignored local workspace, freezes the
selected scenario and exact policy strings, then runs each condition once. Never
overwrite an earlier run. Reject an exact scenario/policy duplicate so ordinary
iteration means changing a policy, not rerolling until an appealing response
appears. A saved-run picker reopens earlier comparisons offline after refresh.

Keep the same one-decision condition budget and four logical request scope. Show
only the divergent generated tutor and student responses in the result tabs;
the durable comparison still retains the shared history. This remains a one-case
mechanism workspace, not a policy-effect estimate or cohort analysis.
